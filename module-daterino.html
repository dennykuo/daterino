# inner setOptions(partialopt)

更新元件選項（例如同一頁切換品牌時，改變可選的上限） - 合併進目前的選項，未傳入的選項維持原值；minDate / maxDate / ranges 同樣可傳入函式 - 元件已初始化時立即重建，並把目前的選取夾進新的上下限（夾回後的日期可由 data 取得） - 元件尚未初始化時只合併選項，待初始化時一併套用 - 不觸發 callback（與 update() 一致）；重建後會再發出一次 daterangepicker:ready 事件 - 開啟中呼叫時維持開啟，但會捨棄尚未套用的選取 - startDate / endDate 只是初始值，重建一律沿用目前的選取；要變更選取請用 update() - 變更 dateFormat 時，目前的選取會轉成新格式；字串型的 minDate / maxDate / ranges 請一併以新格式傳入
